Редактирование страницы из репозитория

Подключите публичный GitHub-репозиторий, выберите HTML-страницу и внесите визуальные правки. Предпросмотр не запускает скрипты сайта. Изменения можно скачать как HTML и вручную добавить в репозиторий.

Публичный репозиторий доступен только для чтения. Авторизация GitHub не запрашивается.
