## Цель активной задачи

Расширить генератор парой полезных разделов и добавить необязательный квиз подбора. Квиз должен быть выключен по умолчанию, использовать только реальные данные проекта и оставаться работоспособным без внешних сервисов. Также добавлена кнопка заполнения редактора вымышленным примером, чтобы быстро увидеть сайт с контентом.
