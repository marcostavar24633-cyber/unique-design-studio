# Design Director Engine — v0.1

## Что реализовано

Первый независимый движок концепций на чистом JavaScript:
- принимает нишу, название, аудиторию, цель, приоритеты контента и историю прошлых концепций;
- оценивает 10 архитектур главной страницы;
- выбирает основной и дополнительный архетип;
- формирует палитру, типографическое направление, направление изображений и motion;
- предлагает последовательность секций и основной CTA;
- учитывает историю до 8 последних концепций и штрафует повторяющиеся композиционные решения;
- возвращает JSON-объект с Design Brief, Design DNA, Homepage, Uniqueness Check и metadata.

## Ограничения текущей версии

Это детерминированная эвристика, не нейросеть и не генератор готового HTML. Совпадения ключевых слов могут быть неполными, особенно для неизвестных ниш и языков. Низкая уверенность означает, что концепцию нужно пересмотреть вручную. Уникальность оценивается по ограниченному набору признаков и не гарантирует отсутствие визуального сходства в готовом дизайне.

## Использование

```js
import { createDesignConcept } from "./src/design-director.js";

const concept = createDesignConcept({
  businessType: "магазин телескопов",
  businessName: "Astro Shop",
  audience: "начинающие астрономы и любители наблюдений",
  primaryGoal: "purchase",
  contentPriority: ["каталог", "подбор по уровню", "сравнение характеристик"]
});

console.log(JSON.stringify(concept, null, 2));
```
