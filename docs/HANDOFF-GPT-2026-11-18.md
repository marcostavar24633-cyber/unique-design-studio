## 3. Инструкция для GPT (скопировать целиком)

Ты продолжаешь разработку UNIQUE DESIGN STUDIO в репозитории `marcostavar24633-cyber/unique-design-studio`. Прочитай `docs/HANDOFF-GPT-2026-11-18.md` и `docs/UNFINISHED_WORK_AND_COMMIT_ROADMAP.md`. Следующая задача — **B03, менеджер промтов**, затем B04 и далее по таблице раздела 2.

**Как устроен проект**
- Движок — ES-модули в `src/engine/` (без сборщика, Node 20+): `concept.js` (концепция и выбор решений), `render.js` (HTML/CSS сайта), `audit.js`, `quality.js`, `autopilot.js`, `prompt.js`, `photo-brief.js`, `image-director.js`, `mechanics.js`, `forms.js`, `text-effects.js`, `motion.js`, `layout-qa.js`, `graphic-art-direction.js`.
- Студия — `studio/index.html` + `studio/studio.js` (один модуль) + `studio/redesign.css`. Форма настроек — массив `GROUPS`; новые выпадающие списки делаются через тип `'@имя'` и `data-special`.
- AI Worker — `worker/index.js` (точка входа: **экспортирует только default**, иначе ломается сборка Cloudflare) и `worker/ai-utils.js` (все помощники и константы).
- Решения дизайна воспроизводимы: `pick(stream(seed, 'ключ'), варианты)` из `util.js`. Ручной выбор владельца хранится в `project.passthrough.<поле>` и сохраняется в экспорте.

**Обязательные правила**
1. Не изменять `main` напрямую. Отдельная ветка на каждую задачу → PR → слияние только через Merge Engine: `gh workflow run merge-engine.yml -f command=merge -f pr=N -f execute=true`, при зелёном CI. Не использовать `--admin` и force-push, не переписывать опубликованную историю.
2. Не удалять существующий функционал и экспорты (Merge Engine блокирует пропажу экспортов — оставляй псевдонимы).
3. Файлы `wrangler.*`, `.github/`, `package.json` — чувствительные: нужна метка `merge-engine: reviewed`, которую ставит владелец. Новые E2E подключай в существующие скрипты (например, в `tests/e2e/responsive.mjs`), а не в `package.json`.
4. Не выдумывать данные: цены, отзывы, токены, результаты поиска. Нет источника — так и показывать («не выполнено», «ориентир»).
5. Доступность обязательна: работа с клавиатуры, `prefers-reduced-motion`, без JavaScript контент виден, контраст WCAG AA.
6. Тесты на каждую новую функцию. Перед PR: `npm test`, `npm run build`, `npm run test:e2e` (нужен Playwright: `npm install --no-save playwright && npx playwright install chromium`). Проверка раскладки (`tests/e2e/layout-matrix.mjs`) должна давать 0 замечаний.
7. Интерфейс — на русском. Промпты для генератора изображений (FLUX) — только на английском, без кириллицы.
8. Не хранить секреты в коде; не выводить токены.
9. После изменений в `worker/` попроси владельца опубликовать Worker: `npx wrangler deploy --config worker/wrangler.jsonc`, затем проверь живой запрос.

**Формат отчёта после каждого этапа:** Выполнено (функции, файлы, PR) · Проверено (тесты, сборка, E2E, ручные проверки) · Не завершено (причины) · Следующий этап (одна задача).
