# Preview App

## Запуск

Из корня репозитория:

```bash
npm run preview
```

Затем откройте http://127.0.0.1:4173.

## Возможности

- Бриф: ниша, название, аудитория и цель сайта.
- Выбор поддерживаемой палитры и геометрии.
- Редактирование заголовка, описания и текста CTA первого экрана.
- Загрузка PNG, JPEG, WebP или GIF до 2 МБ.
- Поле alt для загруженного изображения.
- Предпросмотр ширины Desktop, Tablet и Mobile.
- Редактирование заголовка, описания, пунктов и CTA в каждой секции с мгновенным обновлением предпросмотра.\n- Загрузка отдельного изображения в секцию и редактирование alt-текста.\n- Экспорт HTML со встроенным CSS и загруженным растровым изображением.

## Безопасность и ограничения

Загруженные изображения считываются локально браузером и встраиваются как Data URL только для PNG, JPEG, WebP и GIF. SVG Data URL не разрешён. Содержимое изображений не отправляется на сервер.

Генератор создаёт каркас страницы. Он не выдумывает отзывы, цены, адреса, характеристики или гарантии. Заполнение остальных секций, реальные ссылки и контакты — следующий этап редактора. Формы на данный момент не отправляют заявки.

## Управление проектами и секциями

- «Сохранить проект» записывает несколько проектов в локальное хранилище текущего браузера.
- «Открыть» восстанавливает выбранный проект; «Удалить» удаляет его локальную копию.
- «Экспорт JSON» создаёт переносимый файл проекта с брифом, контентом, порядком секций и встроенными изображениями.
- «Импорт JSON» открывает ранее экспортированный файл. Максимальный размер файла — 8 МБ.
- Секции можно добавлять из списка, перемещать вверх/вниз и удалять. На странице должна оставаться минимум одна секция.
- Порядок секций сохраняется в проекте и применяется при повторной генерации.

Локальная библиотека привязана к браузеру и профилю устройства. Для резервной копии и переноса между устройствами используйте JSON-экспорт. Изображения хранятся внутри JSON, поэтому файлы с большим количеством изображений могут занимать заметное место.

## Редактор карточек товаров и услуг

Внутри каждой секции доступен блок «Карточки товаров / услуг». Можно добавлять и удалять карточки, редактировать название, описание, цену, текст и адрес ссылки, загружать изображение и задавать alt-текст. Ограничение — 24 карточки на секцию. Данные карточек попадают в HTML-предпросмотр, JSON-проект и экспорт HTML. Внешние URL проходят ту же проверку безопасности, что и остальные ссылки; небезопасные схемы не выводятся.
