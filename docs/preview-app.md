# Preview App

## Запуск

Из корня репозитория:

```bash
npm run preview
```

Затем откройте http://127.0.0.1:4173.

## Возможности

- Бриф: ниша, название, аудитория и цель сайта.
- Выбор поддерживаемой палитры и геометрии.
- Редактирование заголовка, описания и текста CTA первого экрана.
- Загрузка PNG, JPEG, WebP или GIF до 2 МБ.
- Поле alt для загруженного изображения.
- Предпросмотр ширины Desktop, Tablet и Mobile.
- Редактирование заголовка, описания, пунктов и CTA в каждой секции с мгновенным обновлением предпросмотра.\n- Загрузка отдельного изображения в секцию и редактирование alt-текста.\n- Экспорт HTML со встроенным CSS и загруженным растровым изображением.

## Безопасность и ограничения

Загруженные изображения считываются локально браузером и встраиваются как Data URL только для PNG, JPEG, WebP и GIF. SVG Data URL не разрешён. Содержимое изображений не отправляется на сервер.

Генератор создаёт каркас страницы. Он не выдумывает отзывы, цены, адреса, характеристики или гарантии. Заполнение остальных секций, реальные ссылки и контакты — следующий этап редактора. Формы на данный момент не отправляют заявки.
