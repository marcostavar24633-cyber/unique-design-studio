# Проверка безопасности и приватности — Unique Design Studio

Дата проверки: 16.11.2026. Ветка: `security/audit` от `main` (193f834).
Метод: ручной разбор кода и подстановка вредоносных данных во все поля проекта. Автотесты: `tests/security.test.mjs`.

Это статическая проверка одного разработчика, а не внешний пентест. Пункты с пометкой «не подтверждено» проверены не полностью.

## Итог

Критических и высоких рисков не найдено. Три пункта низкого уровня перечислены ниже, исправлять их сейчас не требуется.

## Не подтверждено

- Сервер AI-генерации Landing Studio (`server/generate-landing-core.js`): ограничение запросов на Vercel и список `ALLOWED_ORIGINS` проверены только по коду. На живом сервере без ключа OpenAI их не проверяли.
- Content-Security-Policy для созданных страниц не задана: она зависит от хостинга клиента.
- Редактор Landing Studio подробно не разбирался, это следующий этап.
