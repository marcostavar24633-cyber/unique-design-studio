# UNIQUE DESIGN STUDIO

Студия для проектирования и сборки самостоятельных визуальных концепций сайтов. Задача — создавать разные архитектуры и интерфейсы для разных ниш, а не перекрашивать один шаблон.

## Движки

- `src/design-director.js` — анализ ниши, аудитории и цели; выбор одной из 10 архитектур.
- `src/visual-identity.js` — палитра, типографика, геометрия, сетка, отступы и графический язык.
- `src/layout-engine.js` — адаптивный план страницы и привязка секций к компонентам.
- `src/component-renderer.js` — генерация семантического HTML и CSS.
- `src/studio-pipeline.js` — единый запуск всех движков от брифа до HTML.
- `src/site-audit.js` — локальная проверка SEO, адаптивных CSS-правил, доступности ссылок и форм, изображений и потенциальных рисков ресурсов.
- `src/export-readiness.js` — обязательный pre-export gate: блокирует скачивание при критических ошибках, предупреждения оставляет неблокирующими.
- `src/zip-export.js` — ZIP32-экспорт и проверка структуры архива, списка файлов и CRC32 перед скачиванием.
- `app/` — браузерная студия с настройкой проекта, предпросмотром, SEO-редактором, техническим отчётом и HTML/ZIP-экспортом.
- `design-system/` — правила архитектуры, токены и принципы интерфейса.

## Быстрый запуск

Требуется Node.js 18 или новее. Установка зависимостей не нужна.

```bash
npm run preview
```

Откройте http://127.0.0.1:4173. Для остановки сервера нажмите Ctrl+C.

Проверка проекта:

```bash
npm run check
```

## Сквозная генерация из JavaScript

```js
import { createStudioProject } from "./src/studio-pipeline.js";

const project = createStudioProject({
  businessType: "магазин телескопов",
  businessName: "Astro",
  audience: "начинающие астрономы",
  primaryGoal: "purchase"
});

console.log(project.html);
```

## Предпросмотр

В интерфейсе можно задать нишу, название, аудиторию, цель, палитру и форму, отредактировать тексты, CTA и изображения секций, а также просмотреть сайт в размерах Desktop, Tablet и Mobile. Секции можно добавлять, удалять и переставлять; внутри них редактируются карточки товаров и услуг с ценами, ссылками и изображениями. Отдельный редактор управляет названием бренда, меню, телефоном, email, адресом, графиком и HTTPS-ссылками на соцсети. SEO-панель редактирует Title, Description, Canonical и OG image; локальный аудит проверяет HTML/CSS, мобильные breakpoint, клавиатурный фокус, reduced motion, ссылки, подписи форм и изображения. Проекты сохраняются в локальной библиотеке браузера или экспортируются/импортируются как JSON. История изменений поддерживает отмену и повтор в текущей вкладке. Готовый сайт можно скачать в HTML или ZIP-архиве с инструкцией. Перед каждым скачиванием студия заново проверяет актуальный HTML; критические ошибки блокируют экспорт, предупреждения не блокируют. ZIP перед скачиванием дополнительно проходит проверку структуры и CRC32.

Предпросмотр использует локальные модули и не требует внешнего API. Для работы браузерных ES-модулей запускайте локальный сервер через `npm run preview`, а не открывайте HTML как `file://`.

## Ограничения

- Design Director и Visual Identity используют детерминированные эвристики, а не генеративную AI-модель.
- Демонстрационная студия создаёт структуру и визуальный макет; фактические тексты, изображения, цены, адреса и контакты нужно добавить и проверить.
- SEO-аудит анализирует исходные HTML/CSS; он не проверяет опубликованный сайт, реальную скорость, HTTP-статусы, Core Web Vitals, контрастность или фактическую индексацию.
- Формы пока демонстрационные и не отправляют заявки.
- HTML-экспорт — одиночный файл с CSS внутри; изображения по внешним путям должны быть доступны отдельно.
- Перед публикацией проверьте мобильную вёрстку, доступность, контраст, ссылки и правовые требования.
