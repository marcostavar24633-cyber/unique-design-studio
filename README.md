# Unique Design Studio

Отдельный проект для разработки уникальных визуальных концепций и дизайн-систем сайтов.

## Состав первой версии
- `design-system/unique-design-architecture.md` — архитектурная спецификация проектирования самостоятельных главных страниц.
- `design-system/README.md` — принципы и устройство дизайн-системы.
- `design-system/tokens.css` и `components.css` — базовые CSS-токены и компоненты.
- `design-system/projects.md` — исходные профили проектов.
- `design-system/motion.md` — правила motion design и reduced motion.
- `design-system/implementation.md` — инструкция подключения.

## Важно
Это перенос спецификации и дизайн-системы из ветки `feature/unique-design-architecture` репозитория `landing-studio`. Это не перенос всего Landing Studio, панели WEB PROJECT CONTROL CENTER, финансового учебного сайта или исполняемого генератора. Архитектурный документ прямо указывает, что спецификация сама по себе ещё не подключает правила к генератору.
